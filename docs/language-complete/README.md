# 中英文补全

补齐界面标签、长文说明、错误/确认提示、占位文字、辅助功能标签、活动消息、数量与时间格式。文本编辑器的保存/取消和键盘完成按钮改为跟随 App 语言，避免依赖系统语言。

- AppLanguageSupplement.swift：补充静态文案。
- AppLanguage.swift：动态数量、时间、步骤及组合文案。
- tools/audit_localization.py：扫描 UI 字符串，排除明确登记的人名、品牌名、内部标识及已处理的动态格式；当前扫描没有遗漏候选。
- review.html：8 个主要页面的中文模拟器截图。

验证：单元测试及跨页面中文、切换英文、重启保留测试通过。保留用户输入、姓名与品牌名；内容照片里的文字不属于可切换界面文字，系统照片选择器/分享面板由 iOS 控制语言。
