# 第 07 组：个人主页、收藏与活动原生还原

基准是用户指定的 `design/review-v1.html` 中第 07 组，对应 `07-profile-v2.png`，包含 P01、P02、P03、P04。已直接读取审阅页及原图，没有以此前简化版 App 截图作为设计来源。

## 本轮实现

- P01：Made Room 品牌与副标题、专属空间封面、叠放头像、姓名与简介、浅绿编辑按钮、三项数据、带下划线的 Makes / Spaces / Drafts 分栏、三列六张作品图。收藏和活动入口放在下方，避免替代原稿的作品区域。
- P02：Saved 标题与说明、All / Tutorials / Spaces / Posts 分类、Reading corner / Weekend makes 两张收藏夹卡片、独立横图和四张缩略图、黄色 New collection 按钮、收藏菜单与本地收藏入口。
- P03：Today / This week 分组，六条原稿活动、独立人物头像、动态缩略图、分隔线、Follow back 和相应内容跳转。正文可使用缩略图下方的完整宽度。
- P04：原稿头像、原生相机按钮、Display name / Username / Bio / Location 四个输入字段、本地用户名格式校验和资料持久化，保存按钮固定在键盘与安全区上方。
- 新增 27 张独立内容素材，总内容素材 44 张。P04 头像中原图的相机 UI 区域已透明化，实际相机按钮由 UIKit 绘制和处理点击。
- 所有文字、按钮、数据、分栏、表单和卡片由 UIKit + Auto Layout 实现。没有整屏截图、OCR 坐标回放或文字图片。

## 交互与数据边界

个人资料编辑会保留已有本地数据；新增字段兼容旧存档。资料保存先校验，再原子写入。相机按钮使用系统照片选择器。

原图的 48 / 12 / 1.2K、样例作品、样例收藏夹和活动消息是设计展示数据，在页面下方标明。真实本地项目、草稿和收藏单独读取本地状态，不伪装成线上粉丝或实时消息。收藏示例打开专属预览；用户创建的收藏进入真实本地集合。关注和活动已读状态仅保存在设备上。

用户名没有后端可用性查询，因此使用“Username format is valid”，而非原稿中的全局可用性断言。现有用户姓名、简介不会为了匹配示例而覆盖。

## 视觉对照与合理差异

[原图 / 实际首屏 / 滚动后截图对照](review.html)

参考手机画布约 333 × 867，实际测试设备 iPhone 17 Pro 为 402 × 874 pt，比例不同。本轮以参考宽度缩放图片、字体和间距，内容超出真实屏幕时原生滚动。没有通过压扁图片或缩小字号来强塞整屏。

P02 / P03 保留了上一轮修正后的返回入口；P04 保存按钮固定，避免在长表单和键盘后不可操作。iOS 26 的导航按钮玻璃底在这四页关闭，恢复原稿简洁的返回箭头。系统状态栏时间和设备形状由系统绘制。

因此，本轮是以指定原图为基准的结构、素材和比例还原，不把跨画布比例、系统控件和真实数据差异包装为逐像素一致。
