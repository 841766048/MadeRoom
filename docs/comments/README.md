# C04 评论布局

参考 design/review-v1.html 第 05 组 C04。

- 顶部作品缩略图及作者摘要。
- 评论数量与 Newest / Oldest 排序菜单。
- 三组白色圆角评论卡片，作者回复缩进并添加连接线。
- 每条评论使用独立头像、姓名、时间、作者标记、回复、点赞及更多操作。
- 底部头像、输入框和发送按钮固定在安全区域／键盘上方，正文不会被遮挡。
- 点击 Reply 指定回复对象，可取消；发送写入本地草稿，提示未发布到网络。
- 点赞状态保存在本地；排序作用于主评论组，作者回复始终保留在对应父评论下。
- 新增界面文案与示例评论支持中文／English 切换。

设计中的 36 条评论改为实际内置的 5 条，用户草稿单独展示。仅复用独立内容照片，所有文本、行布局、控件均为 UIKit。

## 回复展示修复

回复按稳定的父评论 ID 保存，发送后立即插入对应评论组，并自动滚动到该回复。输入框清空，回复目标复位；不再用成功弹框打断浏览。新评论继续标记为本地草稿，数量包含本地回复。旧字符串草稿按可识别的回复对象归组，普通草稿作为独立评论显示。

## 回复视觉统一

按用户要求取消回复状态标签和浅绿色背景。新增回复复用普通评论行：头像、姓名、相对时间、正文、回复、点赞和更多按钮；父评论关系与保存逻辑保持不变。旧回复缺少时间戳时不编造时间。
