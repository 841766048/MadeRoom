# Make 流程修正

参考审阅页第 02 组 M02–M04、第 03 组 M05、第 12 组 M06/M07，并保留固定底部操作栏。

- 新建：封面选择、名称、教程卡片、空间选择、材料清单、固定创建按钮。
- 详情：项目名称、真实进度条、空间/教程入口、独立材料勾选、照片与笔记区域、步骤列表。
- 步骤：步数、标题、图片、说明、照片/笔记入口、固定 Previous 与完成按钮。Previous 只浏览上一项，不撤销已完成进度；已完成步骤使用 Next step，不重复增加进度。
- 完成：居中完成标题、完成数量、作品照片、空间选择、本地可见性说明、保存/分享入口。
- 笔记：项目卡片、照片、输入、固定保存，以及真实的历史笔记。
- 编辑：作品照片、名称、空间、材料及步骤列表，固定保存按钮。

数据修正：创建/编辑保存选中的空间；材料及勾选按项目存储；新增材料可见；更换图片能够即时预览；选择空间后刷新显示；旧存档兼容新增可选字段。

界面由 UIKit 原生控件构建，独立图片资产不包含 UI 控件。用户自己的图片、名称、笔记、材料与进度优先；无后端，不模拟公开发布。编辑页支持按行编辑步骤，增删或调整顺序后仅保留未改变的已完成前缀；使用文本编辑入口，尚未实现设计图里的拖动排序手柄。不同步骤暂共用指导照片，未声称全流程逐像素 1:1。

验证：23 项单元测试及 2 项 Make UI 流程通过（新建到完成、保存空间、编辑页往返、上一页不撤销进度、缩短步骤后的索引保护）。review.html 包含 M02–M07 模拟器截图。
