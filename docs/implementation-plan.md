# Made Room UIKit Implementation Plan

**Goal:** 原始高保真图作为视觉基准，建立 Swift + UIKit 原生工程，接通 56 个页面入口和本地制作/收藏/空间/社区草稿流程。
**Architecture:** UIKit 导航协调器 + 可复用原生页面布局 + Foundation 持久化状态。设计布局数据提供图像、文字和矢量背景的坐标，不包含整屏截图；图片只用于插画、照片和图标。表单和操作使用 UIKit 控件。
**Tech Stack:** Swift 5、UIKit、Foundation Codable、XCTest，iOS 17+，XcodeGen。

## Constraints
- 用户已明确批准按原设计实施，最新指令 Swift + UIKit 覆盖旧 SwiftUI 规划。
- 英文界面；不引入 SwiftUI、Flutter、WKWebView。
- 56 个稳定设计 ID；实际系统状态栏/安全区/键盘，不把图上的手机外框带入 App。
- 本地行为可运行且跨启动持久化；网络登录、远程发布、审核和同步没有服务配置，不伪造成功。
- 原始图像资源不等于可编辑三维场景；不声称逐像素验收通过。
