# App 弹层 UI

参考完整设计审阅页第 14 组 X11 / X13（底部确认层）和第 15 组 DS01 / DS02（拖动条、圆角按钮与品牌色）。

- App 自有提示、确认及选项菜单统一使用 UIKit 原生 `RoomDialogController`。
- 底部白色卡片、24pt 顶部圆角、32×4pt 拖动条、暗色遮罩。
- 确认框使用并排灰色取消与红色删除按钮；普通提示使用绿色按钮；菜单使用中性色列表。
- 点击取消、遮罩或下滑关闭可取消的弹层；操作回调在关闭动画完成后执行。
- 长内容可滚动，支持 Dynamic Type、VoiceOver 模态焦点与减少动态效果。
- 退出圈子的按钮明确显示 Leave circle。项目菜单直接弹出删除确认。
- 系统照片选择器、系统分享面板仍由 iOS 提供。

这是按共享设计组件实施的适配版本。设计图没有定义所有菜单与业务提示，未定义部分沿用同一组件规范；本地模式文案保留真实服务状态，不能声称所有弹层逐像素 1:1。

验证：20 项单元测试及项目完成、保存草稿两项 UI 流程通过；另有专门的确认取消与菜单选择截图测试。
