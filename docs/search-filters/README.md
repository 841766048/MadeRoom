# 搜索筛选弹层

参考设计审阅页第 01 组 D02 Search。

- 白色圆角底部弹层，顶部系统拖动条，左对齐 Filters 标题。
- Skill level：All、Beginner、Intermediate、Advanced。
- Time needed：Any、Under 2 hours、2–4 hours、Over 4 hours。
- 每组单选；选中项绿色白字并显示勾，未选中项浅灰。
- 底部绿色 Apply filters 固定在安全区域内；内容可滚动，弹层可展开。
- 修改暂存在弹层内；点击应用才写入本地偏好，下滑关闭不提交。
- 重新打开恢复已应用选项；条件用于当前本地教程匹配，缺少匹配时显示 No matches yet。

当前本地目录只有一项真实接入的教程，结果数量不伪装成设计图中的 32 条。空间与创作者不使用教程技能和时长筛选。搜索页面本身的列表布局不属于本次弹层修改。
