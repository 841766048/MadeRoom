# 中文 / English

入口：我的 → 设置 → 语言。默认 English，选择持久化到本机；切换立即刷新当前页与底部导航，其他页面在显示时刷新。无需重启 App。

AppLanguage 管理界面翻译、数量与进度格式，公共 UIKit 标签、按钮、导航、弹层与筛选组件在显示时取对应文案。界面切换不会改写持久化路由、偏好键、项目、笔记或其他用户内容。已保存的内容保留原文；系统相册、分享等系统控件跟随 iOS 自身语言。

内置内容图片中的文字不随界面语言改变；部分示例长文仍保留英文。语言选择不涉及联网翻译。

测试：23 项原有单元测试通过；新增 UI 测试验证中文即时更新、退出重启保留、导航标签更新和切回英文。UI 测试使用独立语言偏好，避免影响正常 App 设置。
