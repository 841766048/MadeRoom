# Make 首页修正

参考：设计审阅页第 02 组 M01 与第 10 组 X02。

## 实现

- M01 改为品牌标题与家居装饰头部、黄色 In progress / Finished 筛选、同排 New project。
- 项目改为横向照片卡片：标题、真实步骤数、进度条、空间名称和操作菜单。
- 恢复底部 Small projects. A happier home. 花瓶横幅。
- X02 使用对应的画笔陶罐插图、居中标题说明、绿色主按钮与描边创建按钮，以及三张灵感缩略图。
- 照片和插图独立导出；文字、按钮、卡片、筛选及进度全部由 UIKit 实现。导出脚本为 tools/export_make_assets.py。
- 保留本地用户数据；不会为了复刻设计图而新增两条虚构项目或写入虚构进度。归档项目从单独入口访问。

## 视觉边界

品牌头部和横幅用原图中的独立装饰素材重新组合，未使用整页截图。屏幕宽高、动态字体及真实项目数量会影响布局。原图的完整背景细节未逐像素重建，本次不宣称整页严格 1:1。项目创建和步骤详情仍沿用现有页面，本次修改聚焦 Make 首页的有项目与无项目状态。

## 验证

20 项单元测试通过；Make 新建 → 项目详情 → 返回列表 → 六步制作 → 保存到空间的 UI 流程通过。截图复核后缩小了 New project 按钮字号，并减少空状态插图占高。
